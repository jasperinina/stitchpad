# Browser support

Primary target: current iPadOS Safari in standalone PWA or browser mode. Current desktop Safari, Chromium, and Firefox are useful secondary targets.

Required APIs: Web Workers, Web Crypto AES/SHA-256, Canvas 2D, Pointer Events, IndexedDB, and Service Workers. Private browsing or managed-device policy may reduce persistent storage guarantees. Apple Pencil is surfaced as a pen pointer; finger marking is disabled by default while two-finger pan/pinch remains available.
